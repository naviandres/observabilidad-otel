% pdf-preamble.tex — fixes de render para el reporte (consumido por `make report`
% via --include-in-header). Justificación: las tablas del reporte tienen celdas
% con tokens largos sin espacios (nombres de exporters, ficheros de figura);
% con columnas p{} de LaTeX esos tokens no se parten y desbordaban sobre la
% columna vecina. Medidas:
%   1. \emergencystretch: tolerancia de estiramiento de línea antes del
%      overfull (reduce cajas desbordadas en párrafos densos).
%   2. xurl: permite partir URLs en cualquier carácter dentro de celdas.
%   3. \small + \raggedright DENTRO de las tablas (no en el cuerpo): celdas
%      alineadas a la izquierda sin justificación forzada, tipografía una
%      talla abajo solo en tablas.
% Fuente de verdad del documento: docs/report/report.md (los anchos relativos
% de columna se fijan ahí, con los guiones de las filas separadoras).
\setlength{\emergencystretch}{3em}
\usepackage{xurl}
\usepackage{etoolbox}
\AtBeginEnvironment{longtable}{\small\raggedright}
\AtBeginEnvironment{tabular}{\small\raggedright}
